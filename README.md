# Глаз Бога: какие данные даёт поиск

Ответ зависит от того, что вы отправили боту и какие совпадения есть в доступных записях. По номеру телефона иногда видны связанные аккаунты и имена. По Telegram ID или нику могут встретиться прежние имена, история ников, упоминания в чатах и контакт, если он был связан с аккаунтом в сохранённой записи.

## От запроса к полям результата

| Что известно | Что может появиться |
| --- | --- |
| Номер телефона | Имена, связанные аккаунты, отдельные записи о контакте |
| Telegram `@username` | Числовой ID, старые ники, датированные упоминания |
| Telegram ID | История аккаунта и связанные контакты, когда такая связь сохранена |
| Email или имя | Совпадения из других периодов и источников |

Таблица описывает возможные поля. У конкретного запроса их может быть меньше. Пустой ответ тоже полезно читать буквально: доступной связи для этого признака могло не оказаться.

## Как проверить найденное

Сначала посмотрите на дату. Затем сравните устойчивые признаки, например ID, с именем и другими деталями. Номер телефона со временем может перейти другому человеку. Старый ник тоже может уже принадлежать другому аккаунту. Если запись касается важного решения, одного совпадения мало.

Отдельно относитесь к выводам об интересах или связях по упоминаниям в чатах. Такая запись показывает наблюдавшийся фрагмент, а не полную историю человека. Не публикуйте чужие персональные данные из результата.

## Частые формулировки запроса

**Какие данные даёт поиск по телефону?** Могут встретиться имя, контактная метка или связанный аккаунт, когда номер есть в подходящей записи.

**Можно ли увидеть скрытый номер?** Иногда историческая запись содержит связь номера с аккаунтом. Текущая настройка видимости Telegram при этом не меняется.

**Что означает пустой ответ?** Для выбранного признака совпавшей записи может не быть. Проверьте формат запроса.
